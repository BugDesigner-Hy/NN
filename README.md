# NN · 神经网络

**在空白处点一下，让一株神经从落点持续向外分叉生长。**

NN 是一个零依赖的单页生成艺术小工具：点击画布即可种下一株「神经网络」，它会沿着随机方向不断向前生长，并按概率分叉出新的分支；所有生长参数都可以用滑杆实时调整。除了平面视图，它还提供一套独立实现的 WebGL2 三维视图，可以在空间中环绕观察神经的生长。

> 纯 HTML + CSS + JavaScript，无构建步骤、无第三方库、无框架。双击 `index.html` 就能跑。

**[▶ 在线试玩](https://bugdesigner-hy.github.io/NN/)** —— 打开即用，点一下画布就开始生长。

---

## 特性

- **点击即生长**：每次点击生成一株独立的神经树，互不干扰，并继承当前参数。
- **两套独立引擎**：平面视图用 Canvas 2D，三维视图用 WebGL2，切换时互不打扰，各自维护自己的场景。
- **10 个实时参数**：初始枝数、生长速度、分叉概率、分叉张角、最大层级、分叉间距、弯曲程度、线条粗细、色相、发光强度。
- **发光质感**：线段做了辉光叠加与色相偏移，深色背景下呈霓虹线稿风格。
- **相机交互**：平面模式可平移缩放，三维模式可环绕、平移、缩放。
- **暂停与导出**：随时暂停生长，并将当前画面导出为带时间戳的 PNG。
- **自适应**：跟随容器尺寸变化，按设备像素比渲染，高分屏不糊。

## 快速开始

线上版：<https://bugdesigner-hy.github.io/NN/>

本地运行不需要安装任何东西，也不需要构建：

```bash

# 方式二：用任意静态服务器（推荐，避免个别浏览器的本地文件限制）
```

## 使用说明

### 平面视图（2D）

| 操作 | 效果 |
| --- | --- |
| 左键点击空白处 | 在落点种下一株新的神经 |
| 按住 `空格` 拖动 | 平移画布（松开空格后恢复点击生长） |
| 滚轮 | 以光标为中心缩放 |

### 三维视图（3D）

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 环绕旋转视角 |
| 右键 / 中键拖动 | 平移视角 |
| 滚轮 | 拉近拉远 |
| 左键单击 | 在空间中落点生长 |

### 通用

- **暂停 / 继续**：停止或恢复生长（暂停时画布静止，便于取景）。
- **清空**：移除当前视图中的所有神经。
- **下载图片**：仅在暂停后出现，导出当前视图的 PNG（文件名带模式与时间戳）。

> 三维视图需要浏览器支持 WebGL2；不支持时该按钮会自动禁用，平面视图不受影响。

## 参数说明

| 参数 | 范围 | 默认值 | 作用 |
| --- | --- | --- | --- |
| 初始神经 | 1–16 | 6 | 一株神经网络从落点同时长出的初始分支数 |
| 生长速度 | 0.2–3 | 1 | 分支推进速度的全局倍率 |
| 分叉概率 | 0–100% | 72% | 到达分叉点后真正分叉的概率（随层级衰减） |
| 分叉张角 | 12–110° | 46° | 子分支相对父分支的张开角度 |
| 最大层级 | 1–14 | 8 | 只限制分叉深度，主线仍会一直向前生长 |
| 分叉间距 | 24–140 | 52 | 相邻分叉点之间的距离基准，越密越「茂盛」 |
| 弯曲程度 | 0–100% | 42% | 生长方向的随机扰动强度，越大越蜿蜒 |
| 线条粗细 | 0.6–5 | 2 | 线宽基准，越靠末端越细 |
| 色相 | 0–360 | 188 | 整体色调，同时驱动界面强调色 |
| 发光 | 0–100% | 68% | 辉光强度 |

每次点击生成的神经都会记住当时的那一套参数，所以调着参数一株株点下去，会得到一片风格各异的「神经网络花园」。

## 技术实现

- **Canvas 2D 增量绘制**：已成熟的线段被写入固定大小的分块（chunk）缓存并只绘制一次，每帧只需重绘正在生长的末端，因此长时间运行也不会掉帧；离屏画布单独承载辉光层，避免重复的 `shadowBlur` 开销。
- **WebGL2 批渲染**：三维视图自己维护生长逻辑（真三维方向、分叉、弯曲），所有线段顶点打包进一块大的顶点缓冲一次上传，用「辉光层 + 实线层」两遍绘制，配合透视投影与可环绕的相机。
- **无依赖交互**：Pointer Events 统一处理鼠标与触屏，`ResizeObserver` + `devicePixelRatio` 保证尺寸与清晰度。

## 浏览器支持

建议使用 Chrome / Edge / Firefox / Safari 的近期版本。平面视图只依赖 Canvas 2D，兼容范围很广；三维视图需要 WebGL2，不支持时「3D」按钮会自动禁用，平面模式不受影响。
